# Rechorder Accidentals

Two-glyph subset derived from Steinberg's Bravura Text 1.482, distributed under the SIL Open Font License 1.1 in `OFL.txt` and embedded in the font's license metadata.

- Source: [BravuraText.otf](https://github.com/steinbergmedia/bravura/blob/37b194378b710cc40e406ab6c4b07608bb9548ae/redist/otf/BravuraText.otf).
- Included: text-sized sharp and flat. Exact comma marks are separate arrow/count text, not quarter-tone glyphs.
- Modified font family: Rechorder Accidentals. The source copyright and license are retained.
- Regenerate with `python subset.py path/to/BravuraText.otf` using FontTools 4.59.0 and Brotli 1.1.0. These tools are not application dependencies.

The font is served locally; the page needs no external font service.
