# AGENTS.md for rechorder

This repository uses worklog for spec and task management.
Worklog entries should be concise and easy to be read easily by outsider humans, but they should not introduce ambiguity or confusions in other ways.
Worklog entries should be formatted in a way that shows logical hierarchy, where 'principles' governs other specifics.
